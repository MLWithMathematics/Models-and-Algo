## 🚀 Getting Started

Follow these instructions to set up and run the notebooks/code on your local machine:

### 🔧 Requirements

You need:

- Python 3.8+  
- Jupyter Notebook / Jupyter Lab  
- Standard ML libraries (e.g., `scikit-learn`, `numpy`, `pandas`, `matplotlib`)

### 📦 Installation

Clone the repo:

```bash
git clone https://github.com/MLWithMathematics/Models-and-Algo.git
cd Models-and-Algo
````

Create and activate a Python virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate   # macOS/Linux
venv\Scripts\activate      # Windows
```

Install dependencies:

```bash
pip install -r requirements.txt
```

> If there is no `requirements.txt`, install packages manually such as:
> `pip install numpy pandas scikit-learn matplotlib notebook`
